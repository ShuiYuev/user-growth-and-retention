# 用户增长与留存专题分析 - 项目需求与实现流程

## 一、 项目需求分析

### 1. 业务背景
目前公司线上业务聚焦于**抖音**兴趣电商平台。随着平台流量红利收窄及同类目竞争加剧，获客成本（CAC）持续走高。旗下核心爆款在抖音端的表现存在显著差异：
* **冷吃毛肚类（短保1个月）：** 属于典型的冲动消费品，但在抖音端的30日复购率近期降至15%。短保特性使得库存周转压力巨大，一旦留存不足即产生高额损耗。
* **牛肉零食（长保10个月）：** 依靠短视频和直播间高频曝光，客单价较高，但用户往往“单次消费”后即处于沉睡状态，购买频次极低。

### 2. 核心分析需求
针对抖音平台的生态特性，本次分析旨在解决以下核心问题：
* **短视频/直播间转化漏斗诊断：** 精准定位用户从刷到视频到点击进入直播间、加购、支付全链路中的核心流失点。
* **抖音用户分层与留存因子：** 探索抖音平台下，哪些行为习惯或内容触点决定了用户的二次回购。
* **“长带短”交叉销售验证：** 利用长保牛肉的高客单价稳住流量成本，探索如何有效带动短保毛肚的快速周转。
* **自动化触达机制：** 针对短保产品，寻找在抖音生态内（如私域、抖店工作台）最佳的复购唤醒周期。

## 二、 项目实现流程

### 阶段一：抖音端数据获取与预处理
* **数据建模：** 从公司数仓中提取抖音渠道近半年的订单流水、直播间流量数据以及数千万行的行为日志（`behavior_log`）。
* **清洗提纯：** 使用 Python (Pandas) 清理非真人账号（爬虫/水军）产生的异常点击，重点提取 `Item_ID`、`Action_Type`（PV/Cart/Buy）、`Stay_Time`（直播间停留时长）等关键指标。

### 阶段二：抖音全链路转化诊断
* **漏斗分析：** 构建 `曝光 -> 详情页 -> 加购 -> 支付` 的转化漏斗。
* **深度洞察：** 发现抖音侧存在显著的“加购未支付”现象，尤其在直播间高压促销环境下，冲动型加购后的冷静期流失率远高于其他平台。
* **流失归因：** 结合退单数据，验证发现支付环节的流失与“配送时效预期”和“优惠券过期提示”强相关。

### 阶段三：基于抖音用户画像的 K-Means 聚类
* **特征工程：** 针对抖音用户特性，构建包含：`近90天消费频次`、`直播间互动深度`、`短保/长保购买比`、`优惠券敏感度` 在内的特征矩阵。
* **聚类实施：** 通过 K-Means 算法将抖音用户划分为：
    * **“深夜食客团”：** 高频购买毛肚，多在 22:00-02:00 下单，对物流时效极度敏感。
    * **“品质大户”：** 购买大包装牛肉为主，下单多受大V带货驱动，客单价高但粘性低。
* **留存锚点：** 挖掘发现，首单购买毛肚后的**第21天**是抖音用户的关键流失节点，此前的交互频次直接决定了其是否会产生二次回购。

### 阶段四：Aha Moment 验证与 LTV 建模
* **行为路径分析：** 识别出抖音端的 Aha Moment：若用户在首单后 7 天内再次进入直播间并领取“毛肚复购券”，其 90 日 LTV 将提升 3.2 倍。
* **策略优化：** 验证了“长保带短保”包裹策略：在牛肉零食包裹中加入毛肚试吃装，并在用户签收后的第 3 天通过抖音私域发送“新鲜度满意度调研”，可显著提升后续留存。

## 三、 业务落地与最终成果反馈

* **策略输出：** 1. 针对抖音加购流失，上线“限时催付”功能，在用户离开直播间 15 分钟内推送钩子产品。
    2. 落地“21天保鲜唤醒计”，针对短保产品进行精准的周期性召回。
    3. 优化直播间排班与选品，在高留存客群活跃时段加大“牛肉+毛肚”组合装的曝光权重。
* **项目成效：** * 抖音渠道**冷吃毛肚 30 天复购率提升了 18%**。
    * 整体**客单价提升 12%**，成功通过长保产品的毛利覆盖了短保产品的获客与周转风险。
    * 建议方案被运营团队全盘采纳，成为抖音官方旗舰店的日常自动化运营 SOP。
